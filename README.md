# Prioneers

Screens transposable element (TE)-encoded proteins for prion-like domains
(PrLDs) using [PLAAC](https://github.com/whitehead/plaac): pull TE proteins
from UniProt by Pfam domain, score them with PLAAC, and report PrLD-positive
rates.

This project has gone through two "pull" strategies as
the questions changed. This README walks through them in the order they were
built, since each stage's result is what motivated the next one.

## Current status

- Two pipelines coexist and are both still relevant: **bulk** (bounded random
  sample across 6 scattered TE-associated Pfam domains) and **clan** (full
  population of one coherent Pfam clan, CL0523). They answer different
  questions — see Stages 1 and 3.
- The one candidate "signal" found so far (CACTA rate elevated over other DNA
  transposon families, Stage 1) has a known pseudoreplication bias that
  hasn't been resolved — see [Open questions](#open-questions).

## Layout

| Path | Stage | Purpose |
|---|---|---|
| `te_bulk_pull.py` | 1 | Fetch/sample TE proteins from UniProt per Pfam domain, score with PLAAC |
| `te_bulk_analysis.py` | 1 | Per-domain PrLD-positive rate breakdown + per-residue plots |
| `plaac_utils.py` | 1 | Shared helpers (run PLAAC, parse its TSV, generate per-residue plots) — used across all stages |
| `te_taxon_analysis.py` | 2 | Adds taxonomic lineage, domain×taxon crosstab, PrLD rate by taxon to the Stage 1 output |
| `te_clan_pull.py` | 3 | Full-population UniProt pull for every Pfam Clan CL0523 domain (no PLAAC scoring) |
| `te_clan_plaac_rescore.py` | 3 | Scores the clan pull with PLAAC at alpha ∈ {0, 0.5, 1} |
| `te_clan_taxon_heatmap.py` | 3 | Cluster-corrected taxon×domain PrLD-rate heatmap across the three alphas |
| `plant_prion_plaac_benchmark.py` | 4 | Standalone: does PLAAC recover known plant PrDs? |
| `tools/plaac/` | — | Bundled PLAAC jar and its R plotting scripts |

## Setup

Full step-by-step instructions (Java, R, conda) are in
[`setup_instructions.md`](setup_instructions.md). Short version:

```bash
conda create -n prioneers python=3.11 -y
conda activate prioneers
pip install -r requirements.txt
```

You'll also need **Java JRE** (to run `tools/plaac/plaac.jar`) and **R +
Rscript** (base R only, for plots — both bundled/no extra install beyond the
interpreters themselves). If `Rscript` isn't on `PATH`, set `RSCRIPT_PATH` to
its full path instead of editing scripts.

Pipeline outputs (Excel files, PLAAC TSVs, plots, UniProt JSON caches under
`data/`) are gitignored — they're regenerated by running the scripts, not
checked into version control.

## Stage 1 — Bulk pull

Randomly samples proteins across 6 scattered TE-associated Pfam domains
(Gag, RT, Integrase, three DDE transposase families) from UniProt and scores
them with PLAAC to get a PrLD-positive rate per domain.

```bash
python te_bulk_pull.py --skip-fetch --per-domain 100 --verbose
python te_bulk_analysis.py --verbose
```

**Interpretation / pivot:** a DNA-transposon, *A. thaliana*-only run found
CACTA's rate sharply elevated (12.0% vs. ≤1.6% for other families, p≈4e-6), scattered-domain design couldn't rule out taxonomic confounding or paralog pseudoreplication which motivated Stages 2 and 3.

## Stage 2 — Taxon add-on

Adds UniProt taxonomic lineage to the Stage 1 output to check whether
per-domain PrLD rates are actually due to differences in taxonomy instead of Pfam domain.

```bash
python te_taxon_analysis.py --verbose
```

**Interpretation / pivot:** confirmed a real taxonomic confound with small,
unevenly-populated domain×taxon cells — motivating Stage 3's full-population
pull instead of a bounded random sample.

## Stage 3 — Clan pipeline pivot

Pulls every UniProt entry (no cap, no subsampling) in Pfam Clan CL0523, then
rescores with PLAAC at three alphas and builds a cluster-corrected (MMseqs2)
taxon×domain PrLD-rate heatmap to remove paralog pseudoreplication.

```bash
python te_clan_pull.py --skip-fetch --verbose
python te_clan_plaac_rescore.py --alpha 0.5 --mode full --verbose   # repeat for --alpha 0.0 and 1.0
python te_clan_taxon_heatmap.py --verbose
```

**Interpretation:** the current best-supported taxon-level view of PrLD rate
for this clan; see `data/results/clan_cl0523_taxon_prld_heatmap*.png`. (One
follow-up file, `clan_cl0523_bacterial_gag_hits.csv`, was produced locally, not a script.

## Stage 4 — Standalone prion benchmark

Scores three literature-validated PrLD proteins (Arabidopsis ELF3 and LD,
yeast Sup35) with PLAAC at three alphas, as an independent check that PLAAC
recovers known PrDs.

```bash
python plant_prion_plaac_benchmark.py --verbose
```

**Result:** Sup35 and ELF3 call a PrD at all three alphas; LD only at
alpha≥0.5 (its least robust call, not evidence against it). EVD (ATCOPIA93)
was scoped but skipped — no UniProt entry or citable protein sequence exists.

## Methodology

**PLAAC parameters** (`CONFIG` in `te_bulk_pull.py`, overridable via
`--alpha`):

PLAAC itself: http://plaac.wi.mit.edu/

- `alpha = 0.5` — blends the background amino-acid distribution PLAAC scores
  against. `alpha=0` uses the input FASTA's own composition as background
  (dataset-specific, unstable on small inputs); `alpha=1` uses a fixed,
  species-generic *S. cerevisiae* background (PLAAC's own CLI default, not
  0.5 — this repo deliberately overrides that). 0.5 is PLAAC's authors'
  recommended balanced default.
- `core_length = 60` — minimum contiguous residue window PLAAC's Viterbi
  parse must find to call a region a prion-like domain (`-c` flag).
- A protein counts as PrLD-positive (`prd_called = 1`) when PLAAC reports
  `PRDlen > 0` — an actual called domain, not just a nonzero score.

**Pfam domains searched** (Stage 1, `TE_PFAM_DOMAINS` in `te_bulk_pull.py`):
PF03732 (PEG10_N-capsid), PF00078 (Reverse transcriptase (RNA-dependent DNA polymerase)), PF00665 (Integrase core domain), PF03004
(	Plant transposase (Ptta/En/Spm family)), PF01498 (HTH_Tnp_Tc3_2), PF03108 (DBD_Tnp_Mut).
No reliable Pfam domain
exists for Helitron Rep/helicase, so Helitrons are under-represented
throughout. UniProt queries are constrained to `length:[50 TO 3000]` to
exclude fragments and multi-domain outliers before PLAAC.

## Open questions/limitations

- **EVD (ATCOPIA93)** protein sequence is unresolved and parked (Stage 4) —
  maps to TAIR locus AT5G17125, no UniProt entry, no annotated CDS.
- **`clan_cl0523_bacterial_gag_hits.csv`** was produced by an ad hoc local
  filter on `clan_cl0523_proteins_plaac_clustered.csv`:
  `broad_group` in `{Bacillati, Pseudomonadati}` and `domain` in the
  `te_capsid` group — bacterial hits for a domain family expected to be
  eukaryotic viral/TE in origin, worth checking for contamination, HGT, or
  misannotation before citing.
